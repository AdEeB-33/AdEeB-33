### 🔥 Featured Projects

#### 🛰️ [ETL Pipeline — Apache Airflow, PostgreSQL & NASA API](https://github.com/AdEeB-33/etl-project)
End-to-end automated ETL pipeline extracting NASA APOD data via REST API, transforming JSON, and loading into PostgreSQL through PostgresHook. Containerized with Docker & Astro Runtime for reproducible daily orchestration via Airflow DAGs.
`Apache Airflow` `Python` `PostgreSQL` `Docker` `Astro Runtime` `SQL`

#### 💳 Full-Stack Web Application
JWT-authenticated platform with role-based access control, secure file uploads (Multer), Stripe payment integration with webhooks, and Pug-templated email notifications. Secured with Helmet, deployed on Heroku.
`Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Stripe` `Multer` `Pug` `Helmet` `Heroku`

#### 🤖 Machine Learning Prediction System
Multi-class classification system using logistic regression, One-vs-Rest, and ensemble methods. Full EDA, feature engineering, and evaluation via confusion matrices and ROC-AUC curves, deployed on AWS.
`Python` `NumPy` `Pandas` `scikit-learn` `Matplotlib` `Seaborn` `AWS`

#### 🛒 [Olist E-Commerce Data Engineering Pipeline](https://github.com/AdEeB-33/big-data-project)
End-to-end Medallion Architecture (Bronze/Silver/Gold) pipeline on the Olist e-commerce dataset. Parameterized ADF pipelines (Lookup + ForEach) ingest CSVs and SQL Server tables into ADLS Gen2; PySpark on Databricks cleans and enriches data (with MongoDB lookups); dimension/fact modeling in Synapse serverless SQL; Tableau dashboards for shipment & sales analytics.
`Azure Data Factory` `Azure Databricks (PySpark)` `Azure Synapse Analytics` `ADLS Gen2` `MongoDB` `MySQL` `Tableau`
